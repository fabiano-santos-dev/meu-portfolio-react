# Meu Portfólio React

Portfólio pessoal desenvolvido com React para apresentar meus projetos, conhecimentos em desenvolvimento web e informações de contato.

## 🚀 Sobre o projeto

Este projeto foi desenvolvido como um portfólio pessoal utilizando React e Vite.

A aplicação possui uma interface responsiva, adaptada para desktop e dispositivos móveis.

## ✨ Seções

- **Hero** — apresentação inicial
- **Sobre Mim** — informações sobre minha formação e objetivos
- **Skills** — tecnologias e ferramentas utilizadas
- **Projetos** — apresentação dos projetos desenvolvidos
- **Contato** — informações de contato e formulário
- **Footer** — navegação rápida e links para redes profissionais

## 🛠️ Tecnologias utilizadas

- React
- JavaScript
- HTML5
- CSS3
- Vite
- React Icons

## 📂 Projetos

### Construlink

Plataforma desenvolvida para conectar clientes a profissionais das áreas de construção, manutenção e reformas.

O projeto permite que clientes encontrem profissionais por especialidade ou região, visualizem seus perfis, acompanhem avaliações e solicitem contato para serviços.

### Meu Portfólio

Este próprio projeto, desenvolvido com React, JavaScript, HTML e CSS para apresentar meus conhecimentos e projetos.

## 💻 Como executar o projeto

### Pré-requisitos

É necessário ter o Node.js instalado.

### Instalação

Clone o repositório:

```bash
git clone https://github.com/fabiano-santos-dev/meu-portfolio-react.git

Entre na pasta:

cd meu-portfolio-react

Instale as dependências:

npm install

Execute o projeto:

npm run dev

Depois acesse o endereço exibido pelo Vite no terminal.
